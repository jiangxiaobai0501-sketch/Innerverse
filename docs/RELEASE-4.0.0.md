# 4.0.0「无界星海」候选发布说明

日期：2026-11-02。基于 3.8.0，保留 Electron/React/R3F/Three.js 架构与依赖声明。

## 操作

H 打开控制界面，进入日记写作或手札；阅读时 H 呼出编辑、收藏和删除。Esc 返回，F11 切换全屏，Alt+F4 关闭。

## 回归与数据

215 项自动化测试通过；真实 Electron 窗口验证了日记增删改查、图片附件与放大、搜索、收藏、阶段编辑、时间轴、图文备份恢复、锁定与解锁。使用独立虚构资料，正式日记未被测试读取或修改。数据、安全与附件服务保持原有格式，未知字段保留，未分类记录不会被自动分配阶段。

最终载荷完成 15 分钟、30 次三档往返，总览/近轨道区间平均约 59.9–60.3 FPS（RTX 5060 Laptop，1920×1080）。预热后显式 GC 的 JS 堆首尾差约 1.18 MiB，同画质资源计数稳定。区间平均不等于逐帧最差值，纹理计数也不等于显存字节。

## 限制

保留密码设置/解锁页。人物档案、关系星图、独立媒体库管理、标签管理、地点、里程碑、可浏览版本历史、富文本编辑器、逐篇私密和随机选择记忆漫游在基线中缺失，未在此版本补建；原镜头巡航保留。应用锁不提供磁盘加密。

未进行正式安装、覆盖升级、卸载、快捷方式或系统信任验收。安装器沿用原应用身份，手工安装可能升级旧安装。核显、多显示器/DPI、睡眠恢复及数小时运行未验收。低/标准档不启用全场景景深，高档仅在飞行时启用。

## 开源参考

沿用 [Three.js](https://github.com/mrdoob/three.js)、[React Three Fiber](https://github.com/pmndrs/react-three-fiber) 及现有依赖；Bloom/DOF 使用已安装 Three.js addons，没有新增大型渲染依赖。新体积密度场与视觉参数为本项目实现，没有复制未声明许可证的银河示例源码。
